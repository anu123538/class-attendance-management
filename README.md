

🛠️ Multi9 Predictive Repair System (PHP & MySQL)

🌟 Project Overview

This is a web-based system developed to digitalize repair shop workflows. It focuses on real-time order tracking and uses predictive logic to help customers and shop owners estimate costs and durations.
+1

🛠️ Tech Stack

Back-end: PHP 
+1


Database: MySQL 
+1


Version Control: Git 
+1


Front-end: HTML, CSS, JavaScript 

🚀 Key Features

Real-time Tracking: Customers can track their repair status in real-time.


Predictive Logic: Estimates repair costs and durations based on historical data.


Workflow Digitalization: Automates manual shop records into a digital system.


Team Collaboration: Managed through Git for efficient code versioning.

🧪 QA & Testing Perspective (PHP focus)
Input Validation: Verified PHP form handling to prevent SQL injection and ensure data security.

Logic Testing: Tested the predictive algorithms with various data sets to ensure accuracy in estimations.

Manual Testing: Conducted end-to-end testing of the repair workflow from order creation to completion.
